# Bash vs Python

En el área de administración de sistemas encontramos como lenguajes principales usados por los administradores **Bash** y **Python**.

## 🐚 Bash

El lenguaje Bash se usa principalmente para comandos y pequeños scripts directamente en la terminal de un servidor Linux. Este lenguaje está centrado en **encadenar comandos del sistema**, no para hacer lógicas complejas — por ejemplo, mover archivos o automatizar tareas repetitivas cortas.

## 🐍 Python

Un administrador pasará a usar el lenguaje Python cuando su intención sea **procesar datos**, **tomar decisiones complejas** o **integrarse con servicios externos**.

Por ejemplo, cuando se quiera hacer uso de estructuras de datos como *listas*, *diccionarios* o *conjuntos*, podemos emplear Bash, pero se encuentra muy limitado. Se empleará el lenguaje Python cuando busquemos:

- Un **manejo de errores** más robusto y menos manual.
- **Parsear formatos de datos estructurados**.
- Realizar **programación orientada a objetos**.

## ⚖️ Conclusión

Esto no quiere decir que el lenguaje Bash sea peor que Python, sino que está **orientado a otras funciones**. Un administrador de sistemas debe controlar ambos lenguajes para poder decidir cuál usar en cada momento dependiendo de la tarea:

- **Bash** → tareas rápidas y directas sobre el sistema operativo.
- **Python** → cuando la lógica y los datos se complican.
